MindShare

A Web API Development project that turned MongoDB, Node.js, Postman, HTML, and CSS into a thought-sharing platform where users could post ideas, edit content, manage profiles, and connect with other people.

One of the main MindShare screens showing the web application's interface and flow.

Course project note: this project was built for a Web API Development module and combined back-end API work with front-end pages for a complete thought-sharing platform.

MindShare was a school project associated with my Web API Development module. The main objective was to build a full web application using MongoDB, Postman, Node.js, HTML, and CSS, so I developed a thought-sharing platform where users could express ideas and interact with other people on the site.

The platform supported core social features such as creating posts, editing existing posts, updating user profiles, and connecting with like-minded individuals. Reading through the actual project files also showed a broader flow that included registration, login, dashboard browsing, searching by username or tags, word lookup support, profile updates, and one-to-one chat.

Platform features

  • Users could create accounts, log in, and access a personalised experience.
  • Posts could be created, updated, and managed through dedicated add and edit flows.
  • Users could update profile details and maintain their account information.
  • The application supported connecting with other users and opening chat conversations.

Application flow

  • Included landing, login, register, dashboard, profile, update profile, add post, and update post screens.
  • The dashboard supported searching by username or tags and included a word-definition section.
  • The connect view listed users for messaging, which linked into a dedicated chat page.

Technical approach

  • Used Node.js for application logic and API handling.
  • Worked with MongoDB for data storage and Postman during API-related development and testing.
  • Built the front-end views with HTML and CSS to support the user-facing experience.
