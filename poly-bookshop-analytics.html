Bookshop Analytics Dashboard

A Data Analytics Visualization Tableau project that combined bookshop and library Excel data into dashboards and a storyboard exploring genre awards, SciFi/Fantasy performance, pricing, sales, and checkout behaviour.

This Data Analytics Visualization project was built in Tableau using linked Excel datasets for a bookshop and its library-related records. The workbook combined information across books, authors, awards, editions, publishers, sales, ratings, catalog copies, and library profiles so the analysis could move beyond single-table summaries.

The Tableau file included both dashboards and a storyboard. From the workbook structure, the main analysis focused on questions such as how many awards each genre received, which author contributed most to SciFi/Fantasy sales, which book had the highest price, and how sales activity related to checkout behaviour.

One part of the project drilled into SciFi/Fantasy specifically, using filters and highlights to narrow the broader genre-level view into a more detailed story. Another part compared sales, checkouts, and the number of books across genres to show how catalogue size and customer demand related to each other.

Analysis questions

Workbook structure

  • Included worksheets such as Genres and awards, Authors and number of sales, Find the highest price of a book, Sales and checkouts, and Sales and number of books.
  • Used a dashboard named SciFi/Fantasy and the price to connect genre awards with pricing analysis.
  • Included a storyboard that stepped through key findings with captions and focused filters.

Data modelling approach

  • Connected multiple Excel sheets covering books, authors, awards, checkouts, editions, publishers, catalog records, ratings, and library profiles.
  • Worked across both bookshop and library datasets so the project could compare sales-side and lending-side behaviour.
  • Used filtering and highlighting to move from broad genre comparisons into focused SciFi/Fantasy analysis.
