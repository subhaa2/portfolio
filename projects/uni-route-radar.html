Route Radar

A Year 1, Trimester 2 Data Structures and Algorithm project completed in 2025 by a team of six students to design a Python flight map routing application that could calculate and rank routes between airports.

Team project note: the goal of this project was not only to apply data structures and algorithms correctly, but also to translate that logic into a usable product through teamwork, algorithm integration, and a clear visual interface. My contribution focused on the UI and on connecting the frontend flow to the backend routing logic.

Route Radar was built for the Data Structures and Algorithm module as a flight map routing project. The application had to model airport connections efficiently, evaluate route options, and present those results in a way that users could understand quickly rather than treating the algorithm as a console-only exercise.

The final product was a functional flight routing application that could calculate the shortest route, the lowest-cost route, and the most effective overall path between airports. The project combined graph-based modelling, Python implementation, route ranking logic, and a visual UI to display route options, total distance, ticket prices, and travel time. In particular, the system used Dijkstra's Algorithm to find the shortest distance between airports and Breadth-First Search (BFS) to find routes with the fewest layovers.

My role was on the product-facing side of the system. I worked on the UI of the app and connected the frontend interactions to the backend algorithm so that the routing logic could be surfaced properly through the interface instead of remaining isolated from the user experience.

Project scope

  • Designed a flight map routing system to find and rank routes between airports rather than returning only a single path.
  • Modelled airport connections using graph-based structures such as adjacency lists so routes could be represented efficiently.
  • Focused on practical outputs that users actually care about, including total distance, ticket prices, travel time, and comparative route quality.

Algorithm focus

  • Used Dijkstra's Algorithm to compute the shortest-distance route between airport nodes in the flight graph.
  • Used Breadth-First Search (BFS) to find routes with the fewest layovers between airports.
  • Applied route-selection logic to compare shortest, lowest-cost, and most cost-effective flight options.
  • Turned theoretical data structures and algorithm concepts into a working application rather than keeping them at pseudocode level.
  • Balanced correctness of the route computations with clarity of presentation so the results would remain understandable to end users.

My contribution

  • Worked on the UI design and presentation of the application so the route results felt clear and usable.
  • Connected the frontend flow to the backend algorithm so route calculations could be triggered and displayed properly in the app.
  • Helped bridge the technical routing logic and the user-facing experience, which was important for the final demo and visualization quality.
